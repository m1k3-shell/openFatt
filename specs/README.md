# Specifiche e schemi ufficiali

Nella repository ci sono solo gli schemi XSD e gli esempi necessari ai test e ai validatori in `tools/`.
I documenti in PDF si scaricano dalle fonti ufficiali:

| Cartella | Contenuto | Fonte |
|---|---|---|
| `xsd/` | Schema FatturaPA VFPR12 1.2.3, firma XML, messaggi SdI 1.1 | fatturapa.gov.it, Documentazione |
| `esempi/` | Fatture di esempio ufficiali (FPA, FPR) | fatturapa.gov.it |
| `notifiche/` | Esempi di ricevute e notifiche SdI | fatturapa.gov.it |
| `lipe/xsd/` | Schema della Comunicazione liquidazioni periodiche IVA (IVP18) | agenziaentrate.gov.it, Comunicazione liquidazioni periodiche IVA |
| `cbi/` | Schemi CBI per bonifici (CBIPaymentRequest 00.04.01) e addebiti SDD (CBISDDReqLogMsg 00.01.01) | progetto OCA/l10n-italy su GitHub (AGPL-3.0) |

Documenti consultati (non inclusi): Specifiche tecniche FatturaPA 1.4 e Elenco controlli 2.0; Specifiche tecniche SdI; specifiche e istruzioni della Comunicazione LIPE 2024; Regole tecniche NSO (MEF); Listino Prezzi Metel, manuale operativo delle definizioni (metel.it).
